# 学习室、维护与交付验收

## 产物结构与主源

尊重用户与已有目录约定。新学习库可采用下列结构，按需要调整，不建无用途的空目录：

```text
topic/
  README.md                 统一入口和启动说明
  plan.md                   范围、路线、目标和预计用时
  sources/                  来源索引、可保存原文和中文解读
  notes/                    Markdown 分章正文
  diagrams/                 图解源码与 SVG
  learning-map.canvas       关联实际章节的学习地图
  practice/                 案例、任务、代码和运行记录
  questions/                自测题和提示
  answers/                  参考答案与实现
  progress.md               状态、误区、复习和下次起点
  room/                     HTML 入口和本地资源
  scripts/                  实际使用的构建与图解生成脚本
  verification.md           实际检查、未验证项和阻塞
```

Markdown 为正文主源，HTML 尽量由其生成，不人工维护两套长正文。图解保留源码与生成脚本或明确再生成步骤，不只交截图。记录必要工具/版本；无渲染器时采用可维护 SVG 等合理方案并说明限制，不伪称导出成功。

Canvas 必须为有效 JSON，有稳定节点 ID、实际文件引用和明确边含义，文件路径相对学习库根目录。图只有外观、未引用笔记不算完成关联。

Markdown/HTML 使用相对链接与本地资源，正确转换 Obsidian 内链和嵌入，不能把 `![[...]]` 留成普通文字。核心图解在正文显示，保留图注和来源。

生成内容与用户回答/进度分离，重新构建不能覆盖用户记录；更新时保留证据并说明修正原因。主源变更后重新生成相关产物并检查一致性。

## HTML 自学路径

首页展示目标、范围、前置知识、地图、目录、推荐顺序和预计用时，有基础/深入/实践入口。从核心且易懂的问题进入正文。

每章根据内容组织目标—问题—原理—图解—案例—练习—自测—复盘，包含完整正文，不仅目录、摘要或外链。提供上下节、相关知识、前置补学及返回路径。

清楚引导当前该阅读、思考、操作或验证什么。提示、答案、参考实现默认折叠，可用原生 details/summary；预测类先展示问题，再主动揭示结果。练习给完成标准与自查方法，复盘有可填写问题。

优先阅读宽度、行距、移动端布局，代码/公式/表格可读，SVG 可放大；基础导航和答案展开能用键盘操作。动效和装饰不能挤占正文或引入无必要的复杂框架。

## 演示和进度

仅在动态过程或参数变化有实质教学价值时制作交互。说明参数、指标、建议实验、变化原因、模型假设和边界，并配静态解释，区分教学模拟与真实行为。

支持阅读进度、自评、疑问、复习标记与复盘记录。本地保存说明具体浏览器/站点范围及清理后可能丢失，提供导出/导入；导入检查格式，不直接丢弃已有记录。

阅读完成、自评掌握和练习证据分开，不根据点击、停留或展开答案自动认定学会。只对可靠判定的题自动评分；开放题提供标准，不用关键词匹配假装理解自由文本。没接真实 AI 服务就不提供假聊天导师或假评估。

静态阅读、图解和基本自测尽量离线可用，避免必须在线加载字体、图标、公式或图解资源。需本地服务时提供依赖、启动命令和准确入口；诚实区分双击可读与需 HTTP 的功能。不默认公开部署或接入外部账号。

## 验收

实际记录结果；静态检查不能代替浏览器目视和运行。工具不可用时注明未验证及影响。

内容：
- 约定范围是否有完整正文、图解、应用与练习，无占位章节？
- 能否解释为什么、走通具体例子、分析前提/反例/误解/取舍？
- 是否解释用在哪里、何时值得用、怎么接入及不适用情形？
- 是否有独立任务、排错和迁移验证？关键结论/真实案例是否有证据，模拟/推论是否标明？

文件与构建：
- 检查 Markdown/HTML 链接、锚点、资源和答案跳转；本地有效与外部未验证分开。
- 解析 Canvas JSON，检查节点/边/文件引用；有 Obsidian 时再检查实际显示。
- 检查源码与 SVG 有效、可显示，文字/连线/图注清楚。
- 运行构建，确认正文、图解和答案同步进入 HTML，用户记录未被覆盖。

页面与实践：
- 用可用浏览器检查首页、代表章节、导航、图解、公式/代码、移动端和答案默认隐藏。
- 验证演示、进度保存、刷新恢复、导出再导入，不仅检查按钮存在。
- 检查离线静态阅读，需服务时按交付命令启动，说明真实边界。
- 实际运行可执行案例并对照预期，阻塞和未运行项明确标未验证。

README 链接地图、章节、实践、来源、进度与 HTML。交付说明入口、启动、范围、实际验证、待完成/未验证项、学习起点和扩展方向。发现不足优先补原理、应用与实践，不用外观掩盖缺口。
